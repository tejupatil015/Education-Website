EGATOR – Online Learning Platform

> A modern, responsive and interactive online learning platform designed to provide students with an engaging and seamless learning experience.


 About The Project

**EGATOR** is a modern educational website created to make online learning simple, accessible and engaging.
The platform allows users to explore courses, learn about instructors, check course fees, read student testimonials and get in touch through the contact section.

The website focuses on a **clean, attractive and user-friendly UI** with responsive layouts, smooth animations and interactive components.


 Key Features

- 🏠 Modern & Attractive Home Page
- 📚 Explore Multiple Courses
- 📖 Detailed Course Information
- 👨‍🏫 Professional Teacher / Instructor Section
- ⭐ Interactive Student Testimonials
- 💰 Course Fees & Pricing Information
- 📩 Contact Us Page
- 💬 User Feedback Section
- 📱 Fully Responsive Design
- ✨ Smooth Hover Effects & Animations
- 🎨 Clean & Modern UI
- 🧭 Easy Navigation
- ⚡ Interactive User Experience


## ⭐ Testimonials
The testimonial section is designed using **Swiper.js** to create a smooth and interactive slider experience.

### Swiper Features Used:

- 🔄 Smooth sliding
- 📱 Responsive slides
- 👆 Touch & swipe support
- ✨ Interactive navigation
- 🎞️ Animated testimonial cards

This makes the testimonial section more engaging and visually appealing for users.

## 🎓 Courses

The Courses section allows students to explore different learning programs and understand the available educational opportunities.

Each course provides relevant information to help students choose the right learning path.

## 👨‍🏫 Teachers

The Teacher section introduces experienced instructors and provides students with information about the people guiding their learning journey.

## 💰 Course Fees

A dedicated fees section provides clear information about course pricing, helping students understand the available learning options.

## 💬 Feedback

The Feedback section allows users to share their experience and opinions about the platform.

## 📩 Contact

The Contact section provides an easy way for students and visitors to connect with the platform for queries and additional information.
